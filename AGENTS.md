# Agent instructions

- Read `CONTEXT.md` before making design, copy or UX changes.
- Inspect the existing implementation before editing.
- Preserve strong existing work; do not protect weak work merely because it already exists.
- Do not invent clients, testimonials, metrics, awards or results.
- Clearly distinguish real proposals and client work from fictional concepts. Use the status documented in `CONTEXT.md`.
- Do not introduce generic SaaS or AI-looking design patterns.
- Maintain responsive behavior and accessibility, including keyboard navigation, visible focus and readable contrast.
- Respect `prefers-reduced-motion`; provide a usable experience without nonessential motion.
- Avoid unnecessary dependencies.
- Run the available build and relevant checks after changes. If no build exists, run checks appropriate to the changed files and report what was verified.
- Do not deploy automatically unless explicitly instructed. Production replacement also requires the review and approval described in `CONTEXT.md`.
- Report changed files and validation results after each task.
